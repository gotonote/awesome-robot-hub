## 核心概念

### 为什么用扩散模型做策略？

- **多模态行为**：自然建模人类演示中的多种合理解法
- **高维动作空间**：支持高维连续控制
- **时序一致性**：对动作序列建模，减少抖动

### 关键技术

| 概念 | 说明 |
|------|------|
| 前向扩散 | 逐步加噪直至纯噪声 |
| 反向去噪 | 从噪声逐步恢复动作样本 |
| 条件生成 | 以观测为条件生成动作 |
| 训练与推理 | 噪声预测目标 + 迭代采样 |
