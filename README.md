## 🎯 这是什么

**物理 AI（Physical AI）** 又称 **具身智能（Embodied AI）**，指具有物理实体、能够在真实或模拟环境中感知、理解并与世界交互的智能系统。

本仓库把碎片化的领域知识整理成 **15 个章节、60+ 篇文档、约 2 万行内容** 的完整学习体系，覆盖从「机器人学基础」到「Diffusion Policy / VLA 大模型」的完整技术栈，**适合初学者到进阶研究者**。

### 与传统 AI 的区别

| 维度 | 传统 AI | 物理 AI / 具身智能 |
|------|---------|-------------------|
| 🗃️ 载体 | 纯软件 / 数据 | 物理实体（机器人） |
| 🔄 交互 | 被动接收数据 | 与环境主动交互 |
| 📚 学习 | 静态数据集 | 在线交互 / 试错 |
| 🎯 目标 | 理解世界 | **理解 + 改变**世界 |

零门槛：无需安装任何依赖，纯 Markdown 内容，GitHub 网页端即可直接阅读。

```bash

cd awesome-robot-hub
# 打开任意章节的 README.md 阅读（或使用 VS Code / Typora 等 Markdown 编辑器）
```
