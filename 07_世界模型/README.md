# 07 世界模型

世界模型（World Model）是智能体对外部环境的内部表示与预测模型，被视为通向通用具身智能的关键方向之一。

## 核心概念

### 为什么需要世界模型？

- **预测未来**：在想象空间中推演动作后果，降低真实试错成本
- **高效规划**：基于内部模型做决策，而非完全依赖环境反馈
- **想象学习**：支持在"梦境"中训练策略，提升样本效率
