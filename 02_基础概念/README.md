## 核心概念

### 机器人学

| 概念 | 说明 |
|------|------|
| 正运动学 | 由关节角求末端位姿 |
| 逆运动学 | 由末端位姿求关节角 |
| 动力学 | 力 / 力矩与运动的关系 |

### 状态估计

- **Kalman 滤波**：线性高斯系统的最优估计
- **粒子滤波**：非线性非高斯系统的近似估计
- **传感器融合**：多源数据互补，提升鲁棒性
