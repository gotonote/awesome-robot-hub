## 一、强化学习概述

### 1.1 什么是强化学习？

强化学习（Reinforcement Learning, RL）是机器学习的一个重要分支，智能体通过与环境交互，以最大化累积奖励来学习最优策略。

## 二、马尔可夫决策过程

### 2.1 MDP定义

马尔可夫决策过程（Markov Decision Process, MDP）是强化学习的数学框架。

**五元组 (S, A, P, R, γ)**：
- **S**：状态空间
- **A**：动作空间
- **P(s'|s, a)**：状态转移概率
- **R(s, a, s')**：奖励函数
- **γ**：折扣因子 (0 ≤ γ < 1)

### 2.2 回报与价值函数

**累计回报**：
$$G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + ... = \sum_{k=0}^{\infty} \gamma^k r_{t+k}$$

**状态价值函数**：
$$V^\pi(s) = \mathbb{E}_\pi[G_t | s_t = s]$$

**动作价值函数**：
$$Q^\pi(s, a) = \mathbb{E}_\pi[G_t | s_t = s, a_t = a]$$

### 2.3 贝尔曼方程

**贝尔曼最优方程**：
$$V^*(s) = \max_a \sum_{s'} P(s'|s, a)[R(s,a,s') + \gamma V^*(s')]$$

## 四、策略梯度方法

### 4.1 REINFORCE算法

**REINFORCE基于蒙特卡洛采样的策略梯度方法**：

$$\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}[\sum_t \nabla_\theta \log \pi_\theta(a_t|s_t) \cdot G_t]$$

```python
# REINFORCE算法
def REINFORCE(env, num_episodes):
    policy_net = PolicyNetwork()
    optimizer = Adam(policy_net.parameters(), lr=3e-4)
    
    for episode in range(num_episodes):
        trajectory = []
        states, actions, rewards = [], [], []
        s = env.reset()
        
        while True:
            probs = policy_net(s)
            a = Categorical(probs).sample()
            s', r, done = env.step(a)
            
            states.append(s)
            actions.append(a)
            rewards.append(r)
            s = s'
            
            if done:
                break
        
        # 计算回报
        returns = compute_returns(rewards)
        
        # 策略梯度更新
        for s, a, G in zip(states, actions, returns):
            probs = policy_net(s)
            log_prob = torch.log(probs[a])
            loss = -log_prob * G
            
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
```

## 五、深度强化学习算法

### 5.1 DDPG (Deep Deterministic Policy Gradient)

**适用于连续动作空间的off-policy算法**：

```python
# DDPG核心代码
class DDPG:
    def __init__(self, state_dim, action_dim):
        self.actor = Actor(state_dim, action_dim)
        self.critic = Critic(state_dim, action_dim)
        self.target_actor = copy(self.actor)
        self.target_critic = copy(self.critic)
    
    def update(self, batch):
        states, actions, rewards, next_states, dones = batch
        
        # Critic更新
        target_q = rewards + gamma * self.target_critic(next_states, 
                                                         self.target_actor(next_states))
        current_q = self.critic(states, actions)
        critic_loss = MSE(current_q, target_q)
        
        # Actor更新
        actor_loss = -self.critic(states, self.actor(states)).mean()
        
        # 软更新目标网络
        soft_update(self.target_actor, self.actor)
        soft_update(self.target_critic, self.critic)
```

### 5.2 PPO (Proximal Policy Optimization)

**PPO通过限制策略更新幅度来提高稳定性**：

```python
# PPO损失函数
def ppo_loss(old_log_probs, new_log_probs, advantages, clip_eps=0.2):
    ratio = torch.exp(new_log_probs - old_log_probs)
    
    # Clipped objective
    clipped_ratio = torch.clamp(ratio, 1 - clip_eps, 1 + clip_eps)
    
    # 优势函数
    loss1 = ratio * advantages
    loss2 = clipped_ratio * advantages
    
    return -torch.min(loss1, loss2).mean()
```

### 6.3 奖励函数设计原则

**设计要点**：
1. **稀疏奖励**：只在任务完成时给予奖励 → 难以学习
2. **密集奖励**：每步给予奖励 → 可能导致次优行为
3. **塑形奖励**：结合稀疏和密集奖励 → 平衡效果

**示例：双足行走奖励**：
```python
def compute_reward(state, action, next_state):
    r_vel =前进速度 * 2.0  # 前进速度奖励
    r_upright =姿态稳定 * 1.5  # 姿态稳定奖励
    r_smooth = -加速度^2 * 0.1  # 平滑奖励
    r_height = -|髋关节高度-目标|^2  # 高度保持
    r_energy = -能耗 * 0.01  # 能耗惩罚
    
    return r_vel + r_upright + r_smooth + r_height + r_energy
```

## 八、总结与展望

### 8.1 强化学习在运动控制中的优势

1. **端到端学习**：直接从感知到控制
2. **处理复杂动力学**：无需精确建模
3. **适应动态环境**：在线学习能力

### 8.2 当前挑战

1. **样本效率**：需要大量交互数据
2. **安全性**：训练过程中可能产生危险行为
3. **可解释性**：黑箱策略难以调试

### 8.3 前沿方向

- **离线强化学习**：从已有数据中学习
- **多任务学习**：一个策略完成多个任务
- **具身智能**：结合大语言模型的推理能力
